On April 1st 2025, we released an update for Oreganized called Carcinogenius, in it we planned to add Asbestos, Bromine, Arsenic and other such materials to the mod with Asbestos being the starting point. Since then we have gotten feedback that these materials can be dangerous in certain contexts so we pulled it out of the mod. HOWEVER for your pleasure only, we decided to remake this into its own addon, so now you can keep asbestos in the game if you wish to play with it, yay!
